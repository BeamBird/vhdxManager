# VHDX 磁盘管理

一个专注 Windows VHDX 虚拟磁盘的轻量工具：创建、挂载、压缩、删除，全部在一个界面完成。

## 运行要求

- Windows 10 / 11（家庭版也可以，无需 Hyper-V）
- .NET 8 桌面运行时
- 必须以**管理员身份**运行（`app.manifest` 已声明 `requireAdministrator`，双击会自动请求提升）

## 功能

| 功能 | 说明 |
| --- | --- |
| 新建虚拟磁盘 | 两步向导：先设定**容量上限**（默认 5 GB）与是否**动态扩容**，最后一步指定**存放位置**和文件名。默认勾选“创建后自动分区、格式化（NTFS）并挂载”。 |
| 添加已有磁盘 | 支持文件对话框多选，或把 `.vhdx` 直接拖进窗口。文件列表会保存到 `%AppData%\VhdxManager\library.json`，下次启动自动恢复。 |
| 挂载 | 一键 `attach`，自动检测新出现的盘符并提示，同时打开资源管理器。已挂载时按钮变为「重新挂载」，用于重新识别盘符。 |
| 卸载 | `detach` 并等待系统释放文件占用。 |
| 压缩 | 回收动态磁盘中未使用的空间：自动卸载 → 只读挂载 → `compact` → 重新挂载，并显示释放了多少空间。 |
| 删除 | 二次确认，必要时自动卸载后永久删除文件（不进回收站）。 |

## 关于“容量上限”和“动态扩容”

- 勾选动态扩容（默认）：文件从几十 MB 开始，随写入内容增长，但**永远不会超过创建时设定的上限**，达到上限后写入失败，需要清理或扩容。
- 取消勾选：创建时立即占满全部容量（固定大小，读写性能更好，但占空间）。

## 实现方式

所有磁盘操作都通过 Windows 内置的 `diskpart` 执行（脚本以系统 ANSI 编码写入临时文件后调用），盘符检测用 `DriveInfo` 做挂载前后差集，因此：

- 不需要 Hyper-V、不需要 PowerShell 模块；
- 兼容 Windows 10/11 家庭版；
- 同一时刻只允许一个 diskpart 脚本运行，避免并发冲突。

磁盘的**容量上限**不走 diskpart，而是直接解析 VHDX 文件结构（Region Table → Metadata → Virtual Disk Size），
所以即使磁盘正被挂载占用、或当前没有管理员权限，也能正确显示。

## 构建与发布

```powershell
# 调试运行
dotnet build
bin\Debug\net8.0-windows\win-x64\VhdxManager.exe

# 发布单文件
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

## 注意事项

- 压缩、挂载、删除前请先关闭正在使用该磁盘的程序，否则会提示“文件被占用”。
- 删除是永久性的，虚拟磁盘内的数据无法恢复。
- 运行异常的堆栈会记录在 `%AppData%\VhdxManager\error.log`。
